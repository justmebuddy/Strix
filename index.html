GitHub JS Vulnerability Scanner

Static analysis runs locally in your browser. Only package names and versions are sent to OSV.dev.

Code injection & XSS

AST + taint tracking from user input to eval, new Function, innerHTML, document.write, dangerouslySetInnerHTML.

Access control

IDOR-shaped routes, missing auth on state-changing endpoints, role fields taken from the request body.

Secrets

OpenAI, Anthropic, Gemini, AWS, Azure, GitHub, npm, Slack, Stripe keys and high-entropy assignments. Values are masked.

Dependencies

package-lock.json / package.json checked against the OSV vulnerability database.

How it works

  1. Reads the repo tree through the GitHub API (default branch).
  2. Downloads JS/TS files (skips node_modules, dist, minified).
  3. Parses each file to an AST and traces user input to dangerous sinks.
  4. Runs secret patterns and dependency checks, then scores the repo.

Findings are heuristics. Test files are down-ranked, and a finding is marked high confidence only when user input was actually traced into the sink.
